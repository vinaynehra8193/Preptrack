
# PrepTrack

### Your Academics. Your Schedule. Your Success.

**PrepTrack** is a Smart Academic Management System developed by **NEXORA** to help students access and manage their academic information in one place.

## About the Project

PrepTrack provides a centralized platform for students and administrators to manage academic schedules, examination datesheets and syllabus information.

## Features

### Student Portal
- Student registration and login
- Personalized student dashboard
- Weekly class timetable
- Today's classes
- Exam datesheet with PDF downloads
- Subject-wise syllabus
- Unit-wise syllabus information
- Student profile management

### Admin Panel
- Two administrator accounts
- Student account management
- Create and manage timetables
- Publish weekly schedules
- Manage examination datesheets
- Upload academic PDF documents
- Manage subjects and syllabus units

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (optional)
- Supabase Authentication
- Supabase PostgreSQL
- Supabase Storage
- Cloudflare Pages
- Git and GitHub
